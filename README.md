# ProjectAtlas-Releases

Public update and theme feed for the MOVYRIX TV Android/Fire TV client.

- GitHub themes: `movyrix/themes/index.json`
- Client release tags: `movyrix-vX.Y.Z`
- APK asset name: `MOVYRIX_TV_vX.Y.Z.apk`

The Android client checks this repository for signed APK updates. Samsung Tizen TVs require a separate Tizen client package; Android APKs cannot be installed on Tizen.
